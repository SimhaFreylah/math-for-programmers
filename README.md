# Математика для программистов

Начальный каркас образовательного сайта: Zensical + Markdown + KaTeX + CSS/JavaScript + Python.

## Открытие в PyCharm (Windows)

1. Распакуйте файлы архива непосредственно в `D:\Projects\math-for-programmers` (рядом с `.venv`, если проект уже создан в PyCharm).
2. В PyCharm откройте **File → Open**, выберите папку проекта.
3. Укажите Python-интерпретатор/создайте окружение `.venv`, если PyCharm не сделал это автоматически.
4. В терминале:

```powershell
python -m pip install -r requirements.txt
zensical serve
```

5. Откройте `http://127.0.0.1:8000/` в браузере.

## Проверка Python-примеров

```powershell
python -m pytest -q
```

## Сборка опубликованного сайта

```powershell
zensical build
```

Готовые файлы будут в папке `site/`.

## Разделение ответственности

- `docs/` — статьи и интерактивные элементы сайта.
- `docs/assets/css/` — общие стили.
- `docs/assets/js/` — интерактивная логика.
- `examples/` — исходный, пригодный для тестирования Python-код.
- `tests/` — автоматические проверки математических примеров.
- `templates/` — шаблоны будущих глав, не публикуемые на сайте.
- `zensical.toml` — конфигурация сайта, разделов, формул и темы.

## Правила

- Не меняйте вручную `site/`: это результат сборки.
- Один урок = один `.md` файл в `docs/`.
- При добавлении урока обновляйте `nav` в `zensical.toml`.
- Сверяйте код в учебнике с проверенными примерами в `examples/`.
- Формулы вводите как `$a+b=c$` или блоками `$$...$$`.

**Примечание:** загрузка KaTeX через CDN требует доступа к интернету при первом открытии страницы.
