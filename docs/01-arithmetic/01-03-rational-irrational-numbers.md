# 01.03. Рациональные и иррациональные числа

*Раздел I. Арифметика · Урок 3 · Уровень: начальный с элементами углублённой теории · Предварительные знания: натуральные и целые числа, чётность*

Сначала изучим математические определения, затем узнаем, как геометрическая задача заставила древнегреческих математиков пересмотреть свои представления о числе, и **строго докажем**, почему $\sqrt2$ нельзя записать обыкновенной дробью. ## 1. Назначение и практический смысл темы

Часто результат действия с целыми числами уже **не является целым**. Например, если $3$ яблока разделить поровну между $4$ людьми, каждый получит:

$$
\frac34=0{,}75.
$$

Для этого достаточно **рациональных чисел** — дробей, образованных из целых чисел.

Но есть геометрические задачи, которые не решаются точно никакой обыкновенной дробью. Самый знаменитый пример — длина диагонали квадрата со стороной $1$:

$$
\boxed{d=\sqrt2}.
$$

Такое число называют **иррациональным**.

Для программиста различие принципиально:

- сумма денежных долей или доля объекта иногда требует **точных дробных вычислений**;
- измерение диагонали или расстояния обычно приводит к **приближённым вычислениям**;
- результаты, которые выглядят одинаковыми на экране, могут храниться в памяти по-разному.

Пока мы не изучаем всю вещественную арифметику. **Задача именно этого урока — понять, какие числа выражаются отношением целых, а какие нет.**

## 2. Математические определения и обозначения

### 2.1. Рациональные числа $\mathbb Q$

**Рациональным** называют число, которое можно представить в виде отношения двух целых чисел:

$$
\boxed{\mathbb Q=\left\{\frac{a}{b}\;\middle|\;a,b\in\mathbb Z,\ b\ne0\right\}.}
$$

Разберём каждую часть записи:

- $\mathbb Q$ — множество **рациональных чисел**;
- $a\in\mathbb Z$ — числитель $a$ является целым числом;
- $b\in\mathbb Z$ — знаменатель $b$ является целым числом;
- $b\ne0$ — знаменатель **не равен нулю**;
- вертикальная черта внутри фигурных скобок читается «таких, что».

Примеры:

$$
\frac12,\quad -\frac34,\quad \frac{7}{5},\quad \frac{-8}{2},\quad 0=\frac01,\quad 11=\frac{11}{1}.
$$

**Любое целое число рационально**, ведь $n=\frac n1$ для любого $n\in\mathbb Z$. Поэтому:

$$
\boxed{\mathbb Z\subsetneq\mathbb Q.}
$$

Знак $\subsetneq$ означает **строгое включение**: все целые числа рациональны, но число $\frac12$ рационально и при этом не целое.

!!! note "Важно"
    Рациональное число — не обязательно положительное и не обязательно записано со знаком дроби. Например, $-3$, $0$ и $0{,}75$ — рациональные числа. Значение числа не зависит от формы его записи.

### 2.2. Равные дроби и несократимая дробь

Одно и то же рациональное число можно записывать разными дробями:

$$
\frac12=\frac24=\frac{50}{100}.
$$

Если числитель и знаменатель имеют общий делитель, отличный от $1$, дробь можно **сократить**. Так, $\frac{18}{24}=\frac34$.

Дробь $\frac pq$ называется **несократимой**, если числитель $p$ и знаменатель $q$ не имеют общего положительного делителя больше $1$. Краткая запись:

$$
\gcd(|p|,|q|)=1,\qquad q\ne0.
$$

Здесь $\gcd$ обозначает наибольший общий делитель (НОД). Мы подробнее изучим НОД в разделе «Теория чисел». Сейчас важно одно: **любую рациональную дробь можно сократить до несократимого вида**.

### 2.3. Десятичная запись рационального числа

Рациональное число может иметь:

1. **Конечную десятичную запись:** $\frac14=0{,}25$.
2. **Бесконечную периодическую запись:** $\frac13=0{,}3333\ldots=0{,}\overline3$.

Знак $\overline3$ означает, что цифра $3$ повторяется бесконечно. Например:

$$
\frac27=0{,}\overline{285714}.
$$

**Теорема.** Действительное число рационально тогда и только тогда, когда его десятичная запись **конечна или начиная с некоторого места периодична**.

Почему это верно? При делении целого числа на ненулевое целое возможны лишь конечное число разных остатков. Если деление не заканчивается, какой-то остаток повторится — а значит, повторятся следующие цифры. Обратное направление можно доказать с помощью геометрической прогрессии или вычитания сдвинутых десятичных записей.

**Мини-пример обратного направления.** Пусть $x=0{,}3333\ldots$. Тогда:

$$
10x=3{,}3333\ldots,\qquad 10x-x=3,
$$

откуда $9x=3$ и $x=\frac13$.

### 2.4. Иррациональные числа

**Иррациональным** называют действительное число, которое **невозможно представить** в виде дроби $\frac ab$, где $a,b$ — целые и $b\ne0$.

Множество иррациональных чисел можно обозначить как разность множеств:

$$
\boxed{\mathbb R\setminus\mathbb Q.}
$$

Это читают так: «все действительные числа, которые не принадлежат множеству рациональных». Здесь символ $\setminus$ означает исключение элементов одного множества из другого.

Примеры иррациональных чисел:

$$
\sqrt2,\qquad \sqrt3,\qquad \pi,\qquad e.
$$

В этом уроке мы строго докажем иррациональность $\sqrt2$. Иррациональность остальных примеров — отдельные математические факты; сами десятичные приближения их не доказывают.

**Десятичная запись иррационального числа бесконечна и непериодична**. Например:

$$
\sqrt2\approx1{,}41421356237\ldots
$$

Знак $\approx$ означает **приблизительное равенство**. Число $1{,}41421356237$ является рациональным приближением, **но не точным значением** $\sqrt2$.

!!! warning "Не путайте"
    Запись $\sqrt2$ — точное обозначение иррационального числа. Запись $1{,}4142$ — рациональное число, приближённо равное $\sqrt2$. Бесконечное количество десятичных знаков **само по себе** не доказывает иррациональность: $\frac13=0{,}333\ldots$ тоже содержит бесконечно много знаков.

### 2.5. Как соотносятся изученные множества?

$$
\boxed{\mathbb N\subsetneq\mathbb Z\subsetneq\mathbb Q\subsetneq\mathbb R.}
$$

| Число | Натуральное $\mathbb N$ | Целое $\mathbb Z$ | Рациональное $\mathbb Q$ | Иррациональное $\mathbb R\setminus\mathbb Q$ |
|---|:---:|:---:|:---:|:---:|
| $5$ | Да | Да | Да | Нет |
| $0$ | Нет* | Да | Да | Нет |
| $-7$ | Нет | Да | Да | Нет |
| $\frac34$ | Нет | Нет | Да | Нет |
| $0{,}\overline6$ | Нет | Нет | Да | Нет |
| $\sqrt2$ | Нет | Нет | Нет | Да |
| $\pi$ | Нет | Нет | Нет | Да |

*В нашем курсе $\mathbb N=\{1,2,3,\ldots\}$, без нуля.*

## 3. Теория, свойства, доказательства и история открытия

### 3.1. Древнегреческая задача: можно ли измерить диагональ квадрата?

Представим квадрат со стороной длиной $a=1$. Проведём диагональ длиной $d$. По теореме Пифагора:

$$
d^2=a^2+a^2=2a^2.
$$

Поскольку длины положительны:

$$
\boxed{d=a\sqrt2,\qquad \frac da=\sqrt2.}
$$

Если $a=1$, то $d=\sqrt2$.

Задача греческих геометров звучала не так, как современный вопрос «Сколько знаков после запятой у $\sqrt2$?». Гораздо важнее было другое: **существует ли общая мера**, которой можно **точное целое число раз** отмерить и сторону квадрата, и его диагональ?

Например, отрезки длины $2$ и $3$ имеют общую меру $1$. Даже отрезки длины $\frac12$ и $\frac34$ имеют общую меру $\frac14$: первый содержит две такие части, второй — три.

Два отрезка называют **соизмеримыми**, если существует положительная длина $u$ и натуральные числа $m,n$, такие что:

$$
a=mu,\qquad d=nu.
$$

Тогда $\frac da=\frac nm$ — рациональное число.

Для стороны и диагонали квадрата оказывается, что **такой общей меры не существует**. Ведь $\frac da=\sqrt2$, а $\sqrt2$ не является рациональным числом. Это и называется **несоизмеримостью стороны и диагонали**.

### 3.2. Немного истории: как греки пришли к несоизмеримости

В древнегреческой математике геометрия и арифметика были тесно связаны. В пифагорейской традиции особенно важны были целые числа и отношения целых чисел — например, при объяснении музыкальных созвучий. Поэтому обнаружение **геометрической длины, которая не выражается отношением целых чисел**, стало существенным расширением привычной картины математических величин.

Точные обстоятельства первого открытия неизвестны. Историки связывают становление теории несоизмеримости с греческой математикой **V века до н. э.**, но **не могут надёжно назвать одного первооткрывателя**. Часто рассказывают, что пифагореец **Гиппас из Метапонта** открыл тайну и был наказан за её разглашение. Это **поздняя легенда, а не установленный исторический факт**; рассказ о его гибели в море не следует преподносить как документированное событие.

Зато известны свидетельства, позволяющие увидеть, что тема была предметом серьёзного исследования:

- В диалоге Платона **«Теэтет» (147d–148b)** обсуждаются работы геометра **Феодора Киренского** о несоизмеримых длинах, связанных с квадратными корнями из чисел вроде $3$, $5$ и далее до $17$. Это не свидетельство самого момента первого открытия, но важное свидетельство развития теории.
- В **«Началах» Евклида, книга X**, систематически различаются **соизмеримые** и **несоизмеримые** величины. Это уже строгая математическая теория.

По современным меркам мы говорим «открыли иррациональные числа». Исторически точнее: **древние греки доказали существование несоизмеримых геометрических величин**. Их представление о числе не полностью совпадало с современным понятием действительного числа.

### 3.3. Почему их назвали *иррациональными*?

Слово **«рациональный»** в математике связано с латинским **ratio** — «расчёт», «отношение», «соотношение». Исторически латинская терминология передавала греческие обозначения, связанные с отношением и объяснением (*logos*). Приставка **ир-** выражает отрицание.

Поэтому в **современном математическом смысле**:

- **рациональное число** — выражается **отношением двух целых чисел** $\frac ab$;
- **иррациональное число** — **не выражается таким отношением**.

Это **не означает**, что иррациональное число «нелогично», «неразумно» или «хаотично». Оно подчиняется строгим математическим законам. Его название связано с невозможностью представить его **целочисленным отношением**.

!!! note "Историческая тонкость"
    Древнегреческие термины и определения из книги X Евклида не во всём совпадают с современным определением $\mathbb Q$ и $\mathbb R\setminus\mathbb Q$. Мы объясняем **современный смысл термина**, а не приписываем грекам современную теорию действительных чисел.

### 3.4. Строгое доказательство: почему $\sqrt2$ нельзя представить дробью

Это главное доказательство урока. Его метод называется **доказательством от противного** (*reductio ad absurdum*): сначала предполагаем противоположное желаемому, а затем показываем, что предположение приводит к противоречию.

**Теорема.** Число $\sqrt2$ иррационально.

**Шаг 1. Предположим, что это рациональное число.** Тогда найдутся целые $p,q$ с $q\ne0$, такие что:

$$
\sqrt2=\frac pq.
$$

Выберем дробь в **несократимом виде**, то есть $p$ и $q$ не могут быть одновременно чётными.

**Шаг 2. Возведём обе части в квадрат.**

$$
2=\frac{p^2}{q^2}\quad\Longrightarrow\quad\boxed{p^2=2q^2}.
$$

Правая часть делится на $2$, следовательно, **$p^2$ — чётное**.

**Шаг 3. Докажем, что $p$ тоже чётное.**

Квадрат любого нечётного целого числа нечётен: если $p=2k+1$, то

$$
p^2=(2k+1)^2=4k(k+1)+1=2\bigl(2k(k+1)\bigr)+1.
$$

Значит, нечётное $p$ не могло бы иметь чётный квадрат. Поэтому $p$ чётно и его можно записать как $p=2r$ для некоторого целого $r$.

**Шаг 4. Подставим $p=2r$.**

$$
(2r)^2=2q^2
\quad\Longrightarrow\quad
4r^2=2q^2
\quad\Longrightarrow\quad
\boxed{q^2=2r^2}.
$$

Теперь **$q^2$ чётное**, а значит, по тому же рассуждению, **$q$ чётное**.

**Шаг 5. Получаем противоречие.**

И $p$, и $q$ — чётные числа, то есть обе величины делятся на $2$. Но в шаге 1 мы выбрали дробь $\frac pq$ **несократимой**. Это невозможно.

Следовательно, первоначальное предположение было ложным:

$$
\boxed{\sqrt2\notin\mathbb Q,\qquad \sqrt2\in\mathbb R\setminus\mathbb Q.}
$$

**Вывод:** никакие целые числитель и ненулевой целый знаменатель не дают дробь, точно равную $\sqrt2$.

!!! tip "Почему нужны были чётные числа?"
    Всё доказательство опирается на пройденную в уроке 01.02 идею: **если квадрат целого числа чётный, то и само число чётное**. Поэтому темы курса связаны между собой, а доказательство не вводит случайных новых правил.

### 3.5. Что ещё можно доказать?

**Утверждение 1.** Сумма рационального и иррационального чисел иррациональна.

Пусть $r\in\mathbb Q$, а $x\notin\mathbb Q$. Если бы $r+x\in\mathbb Q$, то и $(r+x)-r=x$ было бы рациональным как разность двух рациональных чисел. Противоречие.

$$
\boxed{r\in\mathbb Q,\ x\notin\mathbb Q\quad\Longrightarrow\quad r+x\notin\mathbb Q.}
$$

**Утверждение 2.** Произведение **ненулевого** рационального числа на иррациональное иррационально.

Иначе из $rx\in\mathbb Q$ при $r\ne0$ следовало бы $x=(rx)/r\in\mathbb Q$. Снова противоречие.

!!! warning "Два иррациональных не всегда дают иррациональное"
    $\sqrt2+( -\sqrt2)=0$ — рациональное число. И $\sqrt2\cdot\sqrt2=2$ — рациональное число. Поэтому вывод о результате зависит от **того, какие именно числа** участвуют в операции.

### 3.6. Почему приближение дробью не равно точному значению?

Можно находить дроби, очень близкие к $\sqrt2$:

$$
1=\frac11,\qquad \frac32=1{,}5,\qquad \frac75=1{,}4,\qquad
\frac{17}{12}\approx1{,}416667,\qquad
\frac{99}{70}\approx1{,}414286.
$$

Каждая дробь **рациональна**. Они становятся всё ближе к $\sqrt2$, но **ни одна не равна ему точно**. Даже миллион верных знаков после запятой не превращает приближение в равенство.

Математически ошибка приближения дробью $\frac pq$ равна:

$$
\boxed{\varepsilon=\left|\sqrt2-\frac pq\right|>0.}
$$

Для рационального приближения $\frac pq$ ошибка всегда **строго положительна**; её можно сделать сколь угодно малой, но не равной нулю.

## 4. Пошаговые примеры вычислений

### Пример 1. Является ли $-\frac{14}{21}$ рациональным числом?

**Шаг 1.** Числитель $-14$ и знаменатель $21$ целые, причём $21\ne0$.

**Шаг 2.** Следовательно, по определению число рационально.

**Шаг 3.** Сократим дробь на $7$:

$$
-\frac{14}{21}=-\frac23.
$$

**Ответ:** $-\frac{14}{21}\in\mathbb Q$.

### Пример 2. Почему $0{,}125$ рационально?

$$
0{,}125=\frac{125}{1000}=\frac18.
$$

Мы представили десятичное число в виде дроби двух целых чисел. **Ответ:** рациональное.

### Пример 3. Является ли $0{,}\overline6$ рациональным?

Обозначим $x=0{,}6666\ldots$. Умножим на $10$:

$$
10x=6{,}6666\ldots
$$

Вычтем исходное равенство:

$$
10x-x=6\quad\Longrightarrow\quad 9x=6\quad\Longrightarrow\quad\boxed{x=\frac23}.
$$

**Ответ:** число рационально, несмотря на бесконечную запись.

### Пример 4. Длина диагонали квадрата

Сторона квадрата $a=3$. Тогда по теореме Пифагора:

$$
d^2=3^2+3^2=18,\qquad d=\sqrt{18}=3\sqrt2.
$$

Приближённая длина:

$$
d\approx 3\cdot1{,}41421356\approx4{,}24264069.
$$

Здесь $3\sqrt2$ — **точное иррациональное значение**, а $4{,}24264069$ — **рациональное приближение**.

### Пример 5. Какое из двух чисел рационально?

Сравним $\sqrt{49}$ и $\sqrt{50}$.

$$
\sqrt{49}=7\in\mathbb Q.
$$

А $\sqrt{50}=5\sqrt2$ — иррационально, поскольку произведение ненулевого рационального $5$ на иррациональное $\sqrt2$ иррационально.

**Вывод:** не каждый квадратный корень иррационален.

## 6. Реализация математических операций на Python

Теперь переходим от теории к программированию. Каждый блок кода в этом разделе **самодостаточен**: необходимые переменные объявлены в нём самом.

### 6.1. Первое отличие: `int` и `float`

```python
whole_number = 3
approximate_number = 0.75

print(type(whole_number))         # <class 'int'>
print(type(approximate_number))   # <class 'float'>
```

- `whole_number = 3` — имя связывается с целым числом типа `int`.
- `approximate_number = 0.75` — имя связывается со значением типа `float`.
- `type(...)` — показывает тип объекта.
- В Python десятичную точку пишут **через `.`**, а не через запятую.

Тип `float` — это **компьютерный формат чисел с плавающей точкой**. Он не обозначает «множество всех иррациональных» или «множество всех действительных». Он хранит ограниченное множество конечных чисел и особые значения; обычные конечные значения `float` имеют точные рациональные значения в двоичной арифметике.

### 6.2. Обыкновенная дробь через `/`

```python
numerator = 3
denominator = 4

result = numerator / denominator
print(result)        # 0.75
print(type(result))  # <class 'float'>
```

**Разбор:**

1. `numerator` — числитель; ему присвоено `3`.
2. `denominator` — знаменатель; ему присвоено `4`.
3. Оператор `/` выполняет обычное деление и при делении целых чисел создаёт результат типа `float`.
4. `print(result)` выводит значение.

Обратите внимание: **математически** $\frac34$ — точное рациональное число. В данном примере значение `0.75` точно представимо в обычном двоичном `float`, но **не всякая** рациональная дробь представляется так точно.

### 6.3. Точные рациональные числа: `Fraction`

В стандартной библиотеке Python есть модуль `fractions`, а в нём класс `Fraction`. Он хранит **рациональные числа точно** как числитель и знаменатель.

```python
from fractions import Fraction

first = Fraction(1, 3)
second = Fraction(1, 6)
result = first + second

print(first)   # 1/3
print(result)  # 1/2
```

Пошагово:

1. `from fractions import Fraction` — подключаем класс `Fraction` из стандартной библиотеки.
2. `Fraction(1, 3)` — создаём дробь $\frac13$ **без округления**.
3. `Fraction(1, 6)` — создаём вторую дробь.
4. `result = first + second` — складываем их по правилам дробей.
5. Выводим результат `1/2` — он остаётся точным.

!!! tip "Дробь и десятичная запись"
    `Fraction(1, 3)` задаёт точную дробь $1/3$, а `1 / 3` создаёт приближённое значение `float`. Это **разные способы представления** математического числа в Python.

### 6.4. Квадратный корень через `math.sqrt()`

```python
import math

number = 2
approximation = math.sqrt(number)

print(approximation)        # примерно 1.4142135623730951
print(type(approximation))  # <class 'float'>
```

Здесь `import math` подключает стандартный модуль математических функций; `math.sqrt(2)` вычисляет **приближение** $\sqrt2$; переменная `approximation` содержит `float`.

!!! warning "Число и его представление"
    Математически $\sqrt2$ — **иррациональное** число. Но результат `math.sqrt(2)` — число `float`, представляющее **рациональное приближение** иррационального числа. Компьютер не хранит бесконечную непериодическую десятичную запись целиком.

### 6.5. Сравниваем рациональную дробь и иррациональное число

```python
import math
from fractions import Fraction

fraction = Fraction(7, 5)
root_approx = math.sqrt(2)
error = abs(float(fraction) - root_approx)

print(fraction)      # 7/5
print(float(fraction))  # 1.4
print(error)         # приблизительная величина ошибки
```

- `float(fraction)` переводит точную дробь в формат плавающей точки;
- `abs(...)` возвращает абсолютную величину числа;
- `error` — **оценка** ошибки по двум приближённым машинным значениям, а не абсолютно точное символическое значение $|\frac75-\sqrt2|$.

### 6.6. Почему `0.1 + 0.2` не всегда равно `0.3` в компьютере?

```python
left = 0.1 + 0.2
right = 0.3

print(left)           # 0.30000000000000004
print(left == right)  # False
```

В точной арифметике $0{,}1+0{,}2=0{,}3$. Но в обычном двоичном `float` десятичные значения `0.1` и `0.2` представляются **приближённо**; после операций возникает погрешность.

Если нужно проверить **приблизительное равенство**, используют `math.isclose()` с подходящими допусками:

```python
import math

left = 0.1 + 0.2
right = 0.3

print(math.isclose(left, right, rel_tol=1e-9, abs_tol=0.0))  # True
```

**Это не проверка иррациональности.** `math.isclose()` лишь сравнивает два машинных значения с выбранной точностью. Строгое доказательство про $\sqrt2$ мы сделали в математической части урока.

### 6.7. Небольшая программа: сравниваем диагональ с дробью

```python
import math

side = 3
numerator = 7
denominator = 5

diagonal_approx = side * math.sqrt(2)
fraction_diagonal = side * numerator / denominator
error_approx = abs(diagonal_approx - fraction_diagonal)

print("Диагональ (приближённо):", diagonal_approx)
print("Дробное приближение:", fraction_diagonal)
print("Оценка ошибки:", error_approx)
```

Эта программа соединяет три навыка: хранение значений в переменных, работу с дробями и численное вычисление геометрической длины. У каждого использованного имени есть присваивание выше в том же блоке.

## 7. Особенности вычислений в компьютере

### 7.1. Большинство `float` — не «иррациональные числа в памяти»

Даже если `float` получен из $\sqrt2$, его машинное значение — **конечная двоичная дробь**, то есть рациональное число. Важное различие:

| Математика | В Python | Что означает |
|---|---|---|
| $\frac13$ | `Fraction(1, 3)` | Точная рациональная дробь |
| $\frac13$ | `1 / 3` | Приближённое значение `float` |
| $\sqrt2$ | `math.sqrt(2)` | Приближение иррационального числа |
| $0{,}1$ | `0.1` | Приближение десятичного числа в обычном двоичном `float` |

### 7.2. Конечные десятичные числа рациональны

Например, число $1{,}41421356$ содержит **восемь цифр после запятой**, но оно точно равно:

$$
\frac{141421356}{100000000}.
$$

Следовательно, это рациональное число. Число знаков после запятой не позволяет определить иррациональность.

### 7.3. Почему нельзя определить иррациональность проверкой `float`?

Любой конечный `float` допускает рациональное представление. Поэтому алгоритм вида `is_irrational(x)` для **произвольного** `float` не может восстановить, получилось ли это значение из $\sqrt2$, из точной дроби или из измерения. Требуется информация **о математическом выражении**, а не только его округлённое значение.

### 7.4. Где нужна точность?

Для точной рациональной арифметики полезен `Fraction`. Для некоторых задач с десятичной арифметикой — `Decimal` со строковыми исходными значениями. Для математических корней и геометрических длин часто достаточно численных приближений, если правильно учитывается ошибка.

## 9. Типичные ошибки и ограничения

**Ошибка 1.** «Иррациональное число — число с очень длинной десятичной записью». Неверно: даже миллион цифр образует конечную рациональную дробь.

**Ошибка 2.** «Любая бесконечная десятичная запись иррациональна». Неверно: $0{,}\overline3=\frac13$.

**Ошибка 3.** «Число $\sqrt4$ иррационально, потому что содержит корень». Неверно: $\sqrt4=2$.

**Ошибка 4.** «Рациональное число обязательно записывается как дробь». Неверно: $5=\frac51$, $0=\frac01$.

**Ошибка 5.** «Деление на ноль допустимо». Неверно: в определении $\frac ab$ обязательно $b\ne0$; в Python попытка делить на ноль приводит к ошибке.

**Ошибка 6.** «Греков достоверно возглавлял первооткрыватель Гиппас, которого утопили». Это легенда, не подтверждённая надёжными данными.

**Ошибка 7.** «`math.sqrt(2)` — точное хранение $\sqrt2$». Неверно: это численное приближение `float`.

**Ошибка 8.** «Два иррациональных при сложении обязательно дают иррациональное». Неверно: $\sqrt2-\sqrt2=0$.

**Ошибка 9.** «`float(1/3)` и `Fraction(1, 3)` одинаково точны». Неверно: в первом случае применяется округление до машинного `float`.

## 11. Краткие выводы и справочник формул

### 11.1. Математический справочник

| Понятие | Обозначение | Что означает |
|---|---|---|
| Рациональное число | $\frac ab$, $a,b\in\mathbb Z$, $b\ne0$ | Отношение двух целых |
| Множество рациональных | $\mathbb Q$ | Все рациональные числа |
| Иррациональные числа | $\mathbb R\setminus\mathbb Q$ | Действительные, не представимые дробью целых |
| Вложенность множеств | $\mathbb Z\subsetneq\mathbb Q\subsetneq\mathbb R$ | Каждое следующее множество шире |
| Диагональ квадрата | $d=a\sqrt2$ | Точная длина при стороне $a>0$ |
| Несоизмеримость | $d/a\notin\mathbb Q$ | Нет общей меры в целое число повторений |
| Иррациональность корня | $\sqrt2\notin\mathbb Q$ | Невозможность записи дробью |
| Абсолютная ошибка приближения | $\left|\sqrt2-\frac pq\right|$ | Расстояние между значениями |

**Главная идея урока:**

$$
\boxed{\mathbb R=\mathbb Q\cup(\mathbb R\setminus\mathbb Q),\qquad
\mathbb Q\cap(\mathbb R\setminus\mathbb Q)=\varnothing.}
$$

Каждое действительное число либо рационально, либо иррационально — **третьего варианта нет**.

### 11.2. Справочник Python

| Запись | Значение |
|---|---|
| `a / b` | Деление; при двух `int` обычно даёт `float` |
| `Fraction(a, b)` | Точная рациональная дробь |
| `import math` | Подключение математических функций |
| `math.sqrt(2)` | Численное приближение $\sqrt2$ |
| `abs(x)` | Абсолютное значение |

**Итог урока.** Рациональные числа — это отношения целых; иррациональные нельзя представить такими отношениями. Геометрия диагонали квадрата приводит к точному числу $\sqrt2$, иррациональность которого можно **доказать**, а не просто предположить по десятичной записи. Python позволяет рассчитывать **точные рациональные дроби** и **приближения иррациональных чисел**, если осознавать разницу между этими двумя видами работы с числами.

(function () {
  function initialise() {
    document.querySelectorAll('[data-irrational-lab]').forEach(function (lab) {
      if (lab.dataset.ready === 'true') return;
      lab.dataset.ready = 'true';
      const sideInput = lab.querySelector('[data-side]');
      const qInput = lab.querySelector('[data-q]');
      const sideOutput = lab.querySelector('[data-side-output]');
      const qOutput = lab.querySelector('[data-q-output]');
      const exact = lab.querySelector('[data-exact]');
      const approximation = lab.querySelector('[data-approx]');
      const fraction = lab.querySelector('[data-fraction]');
      const error = lab.querySelector('[data-error]');
      const bar = lab.querySelector('[data-bar]');
      const barNumber = lab.querySelector('[data-bar-number]');
      const sideLabel = lab.querySelector('[data-side-label]');
      const diagonalLabel = lab.querySelector('[data-diag-label]');
      const code = lab.querySelector('[data-code]');
      const copy = lab.querySelector('[data-copy-code]');
      const reset = lab.querySelector('[data-reset]');

      function update() {
        const a = Number(sideInput.value);
        const q = Number(qInput.value);
        const p = Math.round(q * Math.SQRT2);
        const ratio = p / q;
        const approximateDiagonal = a * Math.SQRT2;
        const epsilon = Math.abs(Math.SQRT2 - ratio);
        sideOutput.textContent = String(a);
        qOutput.textContent = String(q);
        exact.textContent = a === 1 ? '√2' : a + '√2';
        approximation.textContent = approximateDiagonal.toFixed(10);
        fraction.textContent = p + ' / ' + q + ' = ' + ratio.toFixed(9);
        error.textContent = epsilon.toFixed(10);
        bar.style.width = String(Math.min(100, ratio * 50)) + '%';
        barNumber.textContent = ratio.toFixed(5);
        sideLabel.textContent = 'a = ' + a;
        diagonalLabel.textContent = a === 1 ? 'd = √2' : 'd = ' + a + '√2';
        code.textContent = 'import math\n\na = ' + a + '\nq = ' + q + '\np = round(q * math.sqrt(2))\nexact_approx = a * math.sqrt(2)\nrational_approx = a * p / q\nprint(exact_approx)\nprint(rational_approx)';
      }
      sideInput.addEventListener('input', update);
      qInput.addEventListener('input', update);
      reset.addEventListener('click', function () {sideInput.value = '1';qInput.value = '5';update();});
      copy.addEventListener('click', function () {
        if (navigator.clipboard && navigator.clipboard.writeText) {
          navigator.clipboard.writeText(code.textContent).then(function () {

          }).catch(function () {copy.textContent = 'Выделите текст кода';});
        } else {copy.textContent = 'Выделите текст кода';}
      });
      update();
    });
