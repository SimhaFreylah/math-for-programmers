# 01.04. Вещественные и комплексные числа

*Раздел I. Арифметика · Урок 4 · Уровень: от начального к углублённому · Предварительные знания: уроки 01.01–01.03*

В первых уроках мы познакомились с **натуральными** и **целыми** числами, затем изучили **рациональные** и **иррациональные**. Пришло время связать эти понятия в общую систему. В этом уроке появятся два новых множества: **вещественные числа** $\mathbb R$ и **комплексные числа** $\mathbb C$.

Главная цепочка первых четырёх тем:

$$
\boxed{\mathbb N\subsetneq\mathbb Z\subsetneq\mathbb Q\subsetneq\mathbb R\subsetneq\mathbb C.}
$$

Мы увидим, почему числа на привычной прямой образуют множество $\mathbb R$, почему уравнение $x^2=-1$ не имеет **вещественных** решений, как появляется мнимая единица $i$ и как комплексное число изображается точкой на плоскости. Затем построим эту точку в **интерактивной лаборатории** и запишем аналогичные вычисления на **Python**.

!!! info "После урока вы сможете"

## 1. Назначение и практический смысл темы

Представьте две задачи.

**Задача А — измерение расстояния.** По горизонтали мы переместились на $3$ единицы, а по вертикали — на $4$. Длина прямого пути равна:

$$
\sqrt{3^2+4^2}=5.
$$

Мы работаем с обычными расстояниями, координатами и длинами: это **вещественные числа**. Сюда входят и целые координаты, и дроби, и иррациональные длины.

**Задача Б — уравнение без вещественного корня.** Требуется решить:

$$
x^2+1=0\quad\Longleftrightarrow\quad x^2=-1.
$$

Ни одно вещественное число, положительное, отрицательное или нулевое, не имеет отрицательного квадрата. Чтобы получить решение, математики расширили множество чисел и ввели **мнимую единицу** $i$, удовлетворяющую равенству $i^2=-1$.

В программировании вещественные приближения нужны для измерений и графиков, а комплексные числа — для моделирования колебаний, обработки сигналов, преобразований Фурье и решения уравнений. **Это не два несвязанных мира:** всякое вещественное число одновременно является комплексным числом с нулевой мнимой частью.

## 2. Математические определения и обозначения

### 2.1. Напоминание: какие множества мы уже знаем?

| Обозначение | Множество | Пример | Главное свойство |
|---|---|---|---|
| $\mathbb N$ | Натуральные | $1,2,3,\ldots$ | Счёт предметов; в нашем курсе $0\notin\mathbb N$ |
| $\mathbb Z$ | Целые | $-3,-2,-1,0,1,\ldots$ | Натуральные, ноль и отрицательные целые |
| $\mathbb Q$ | Рациональные | $-\frac34,\;\frac12$ | Представимы как $\frac pq$ с $p,q\in\mathbb Z$, $q\ne0$ |

Обозначение $A\subsetneq B$ означает **строгое включение**: все элементы множества $A$ входят в $B$, но в $B$ есть и другие элементы.

Например, $\mathbb Z\subsetneq\mathbb Q$, поскольку любое целое число можно записать как $\frac n1$, но $\frac12$ целым не является.

### 2.2. Вещественные числа $\mathbb R$

**Вещественные числа** — это рациональные **вместе с иррациональными**. Именно они соответствуют всем точкам обычной непрерывной числовой прямой.

$$
\boxed{\mathbb R=\mathbb Q\cup(\mathbb R\setminus\mathbb Q).}
$$

Здесь $\cup$ — объединение множеств, а $\mathbb R\setminus\mathbb Q$ — множество иррациональных чисел, о которых шла речь в уроке 01.03. Формула описывает разбиение вещественных чисел на две непересекающиеся части.

Примеры вещественных чисел:

$$
-7,\quad 0,\quad \frac34,\quad -1{,}25,\quad \sqrt2,\quad \pi.
$$

Число может быть **одновременно** натуральным, целым, рациональным и вещественным: так, $5\in\mathbb N$, $5\in\mathbb Z$, $5\in\mathbb Q$, $5\in\mathbb R$.

!!! note "Точная математическая формулировка"
    В математике $\mathbb R$ характеризуют не только перечислением рациональных и иррациональных чисел. Это **полное упорядоченное поле**. Простыми словами: в нём действуют знакомые арифметические правила и сравнения, а на числовой прямой нет «недостающих точек». Формальное определение полноты изучают позднее в математическом анализе.

### 2.3. Числовая прямая

Вещественное число изображают точкой на прямой, где выбраны начало отсчёта $0$, единичный отрезок и положительное направление.

- Число $-2$ располагается слева от $0$.
- Число $3$ располагается справа от $0$.
- Число $\frac12$ находится на середине между $0$ и $1$.
- Число $\sqrt2\approx1{,}4142$ лежит между $1$ и $2$, хотя не является рациональным.

Положение на прямой позволяет сравнивать любые два вещественных числа: для них определены отношения $<$, $>$ и $=$.

### 2.4. Почему вещественных чисел бывает недостаточно?

Возьмём уравнение:

$$
x^2=-1.
$$

Если $x\ge0$, то $x^2\ge0$. Если $x<0$, произведение двух отрицательных чисел тоже неотрицательно, поэтому снова $x^2\ge0$. Следовательно, **ни одно** $x\in\mathbb R$ не удовлетворяет равенству $x^2=-1$.

Чтобы научиться решать такие уравнения, вводят новый объект — **мнимую единицу**:

$$
\boxed{i^2=-1.}
$$

Символ $i$ не обозначает число, расположенное где-то левее нуля: он расширяет систему чисел **за пределы вещественной прямой**.

### 2.5. Комплексные числа $\mathbb C$

**Комплексное число** — число вида

$$
\boxed{z=a+bi,\qquad a,b\in\mathbb R,\quad i^2=-1.}
$$

- $a$ — **вещественная часть**: $\operatorname{Re}(z)=a$;
- $b$ — **мнимая часть**: $\operatorname{Im}(z)=b$;
- $bi$ — **мнимая составляющая** числа.

Важно: мнимая часть — именно **вещественный коэффициент $b$**, а не всё выражение $bi$.

**Пример:**

$$
z=3+4i,\qquad\operatorname{Re}(z)=3,\qquad\operatorname{Im}(z)=4.
$$

Другие примеры:

| Запись | Вещественная часть | Мнимая часть | Как называют |
|---|---:|---:|---|
| $2+3i$ | $2$ | $3$ | Комплексное, невещественное |
| $-1-5i$ | $-1$ | $-5$ | Комплексное, невещественное |
| $7+0i$ | $7$ | $0$ | Вещественное число |
| $0+2i$ | $0$ | $2$ | Чисто мнимое, ненулевое |
| $0+0i$ | $0$ | $0$ | Ноль |

### 2.6. Почему $\mathbb R\subsetneq\mathbb C$?

Всякое вещественное число $a$ можно записать в комплексной форме:

$$
a=a+0i.
$$

Следовательно, $a\in\mathbb R\Longrightarrow a\in\mathbb C$. Но $i\in\mathbb C$, тогда как $i\notin\mathbb R$, поэтому включение **строгое**:

$$
\boxed{\mathbb R\subsetneq\mathbb C.}
$$

И теперь у нас есть вся цепочка первых уроков:

$$
\boxed{\mathbb N\subsetneq\mathbb Z\subsetneq\mathbb Q\subsetneq\mathbb R\subsetneq\mathbb C.}
$$

### 2.7. Комплексная плоскость

Вещественные числа удобно помещать на **прямой**. Для комплексного числа нужны уже **две координаты**: $a$ и $b$.

$$
z=a+bi\quad\longleftrightarrow\quad(a,b).
$$

Горизонтальная ось называется **вещественной** ($\operatorname{Re}$), вертикальная — **мнимой** ($\operatorname{Im}$). Например, $3+4i$ соответствует точке $(3,4)$: три шага вправо и четыре вверх.

Комплексную плоскость также называют **плоскостью Аргана**. Мы построим её в интерактивной части урока.

## 3. Теория, свойства и доказательства

### 3.1. Вещественные числа можно складывать, умножать и сравнивать

Для $a,b\in\mathbb R$ выполняются знакомые свойства:

$$
a+b\in\mathbb R,\qquad a-b\in\mathbb R,\qquad ab\in\mathbb R.
$$

Если $b\ne0$, то $\frac ab\in\mathbb R$.

Для любых вещественных $a,b$ справедливо **ровно одно** из трёх утверждений:

$$
a<b,\qquad a=b,\qquad a>b.
$$

Вместе с полнотой это делает вещественную прямую естественной моделью величин: координат, длин, времени, температуры и многих физических измерений.

### 3.2. Доказательство: $x^2=-1$ не имеет вещественных решений

**Утверждение.** Для каждого вещественного $x$ его квадрат неотрицателен:

$$
\forall x\in\mathbb R:\quad x^2\ge0.
$$

**Доказательство.** Если $x\ge0$, произведение $x\cdot x\ge0$. Если $x<0$, произведение двух отрицательных множителей положительно. При $x=0$ квадрат равен нулю. Итак, $x^2\ge0$ во всех случаях.

Следовательно, равенство $x^2=-1$ невозможно в $\mathbb R$, ведь $-1<0$. **Это обоснование необходимости расширения чисел**, а не просто условное правило о букве $i$.

### 3.3. Степени мнимой единицы

Из определения $i^2=-1$ последовательно получаем:

$$
\begin{aligned}
i^1&=i,\\
i^2&=-1,\\
i^3&=i^2\cdot i=-i,\\
i^4&=i^2\cdot i^2=1,\\
i^5&=i.
\end{aligned}
$$

Далее значения повторяются с периодом $4$:

$$
\boxed{i^{n+4}=i^n,\qquad n\in\mathbb N.}
$$

Это свойство пригодится при упрощении выражений и вычислении степеней комплексных чисел.

### 3.4. Сложение комплексных чисел

Пусть $z_1=a+bi$, $z_2=c+di$. Складываем отдельно вещественные и мнимые части:

$$
\boxed{(a+bi)+(c+di)=(a+c)+(b+d)i.}
$$

Например:

$$
(2+3i)+(4-i)=6+2i.
$$

На комплексной плоскости это соответствует сложению двумерных векторов.

### 3.5. Умножение комплексных чисел

Умножаем как обычные скобки, затем используем $i^2=-1$:

$$
\begin{aligned}
(a+bi)(c+di)&=ac+adi+bci+bdi^2\\
&=(ac-bd)+(ad+bc)i.
\end{aligned}
$$

Итак,

$$
\boxed{(a+bi)(c+di)=(ac-bd)+(ad+bc)i.}
$$

Эта формула объясняет, почему при умножении комплексных чисел недостаточно просто перемножить вещественные части отдельно от мнимых.

### 3.6. Сопряжённое комплексное число

**Сопряжённым** к $z=a+bi$ называют число

$$
\boxed{\overline z=a-bi.}
$$

Например, если $z=3+4i$, то $\overline z=3-4i$. Их точки симметричны относительно вещественной оси.

Перемножим число на сопряжённое:

$$
\begin{aligned}
z\overline z&=(a+bi)(a-bi)\\
&=a^2-(bi)^2=a^2+b^2.
\end{aligned}
$$

Получается важное неотрицательное вещественное число.

### 3.7. Модуль комплексного числа

**Модуль** комплексного числа — расстояние от точки $(a,b)$ до начала координат:

$$
\boxed{|z|=\sqrt{a^2+b^2}.}
$$

Эта формула следует из теоремы Пифагора. Например:

$$
|3+4i|=\sqrt{3^2+4^2}=5.
$$

Для вещественного $a$ (то есть когда $b=0$) получается обычный модуль числа:

$$
|a+0i|=\sqrt{a^2}=|a|.
$$

Кроме того,

$$
\boxed{z\overline z=|z|^2.}
$$

### 3.8. Почему комплексные числа нельзя упорядочить обычным образом?

Для вещественных чисел можно сказать $5>3$. А вот сравнение $3+2i>1+i$ **не имеет стандартного смысла**.

Причина глубже, чем ограничение языка Python. Нельзя задать на **всём** $\mathbb C$ порядок, совместимый с обычными правилами сложения и умножения упорядоченного поля.

**Доказательство от противного.** В любом упорядоченном поле квадрат ненулевого элемента положителен. Но у ненулевого $i$ квадрат равен $-1$. Это противоречило бы тому, что $-1<0$. Следовательно, упорядочить комплексные числа таким способом нельзя.

Вместо этого можно сравнивать **модули** $|z_1|$ и $|z_2|$, ведь они вещественные. Однако сравнение модулей — это **не** сравнение самих комплексных чисел.

!!! tip "Углублённо"
    Комплексные числа удобны ещё и тем, что любой многочлен ненулевой степени с комплексными коэффициентами имеет комплексный корень (основная теорема алгебры). Пока мы не доказываем эту теорему: к ней вернёмся после изучения алгебры.

## 4. Пошаговые примеры вычислений

### Пример 1. К какому множеству относится число $-\sqrt2$?

1. По уроку 01.03 число $\sqrt2$ иррационально. Его отрицание $-\sqrt2$ тоже иррационально.
2. Иррациональные числа входят в $\mathbb R$.
3. Любое вещественное число входит в $\mathbb C$ как $a+0i$.

**Ответ:** $-\sqrt2\in\mathbb R$, $-\sqrt2\in\mathbb C$, но $-\sqrt2\notin\mathbb Q$. Наименьшее из пяти изученных множеств — $\mathbb R$.

### Пример 2. Выделяем части комплексного числа

Дано $z=-2+5i$.

**Шаг 1.** Сравниваем запись с $a+bi$: $a=-2$, $b=5$.

**Шаг 2.** Записываем:

$$
\operatorname{Re}(z)=-2,\qquad\operatorname{Im}(z)=5.
$$

**Шаг 3.** На плоскости отмечаем точку $(-2,5)$: две единицы влево, пять вверх.

### Пример 3. Складываем комплексные числа

$$
(3+2i)+(-1+5i).
$$

**Шаг 1.** Складываем вещественные части: $3+(-1)=2$.

**Шаг 2.** Складываем мнимые части: $2+5=7$.

**Ответ:**

$$
\boxed{(3+2i)+(-1+5i)=2+7i.}
$$

### Пример 4. Умножаем комплексные числа

$$
(2+3i)(1-2i).
$$

**Шаг 1.** Раскрываем скобки:

$$
2-4i+3i-6i^2.
$$

**Шаг 2.** Подставляем $i^2=-1$:

$$
2-i+6.
$$

**Ответ:**

$$
\boxed{(2+3i)(1-2i)=8-i.}
$$

### Пример 5. Находим сопряжённое и модуль

Пусть $z=3+4i$.

**Сопряжённое число:** $\overline z=3-4i$.

**Модуль:**

$$
|z|=\sqrt{3^2+4^2}=\sqrt{25}=5.
$$

**Проверка:**

$$
z\overline z=(3+4i)(3-4i)=25=|z|^2.
$$

### Пример 6. Решаем уравнение без вещественных корней

$$
x^2+4=0.
$$

**Шаг 1.** Переносим $4$ вправо: $x^2=-4$.

**Шаг 2.** Используем $i^2=-1$. Тогда $(2i)^2=4i^2=-4$.

**Шаг 3.** Учитываем оба знака:

$$
\boxed{x=2i\quad\text{или}\quad x=-2i.}
$$

Проверка: $(\pm2i)^2+4=-4+4=0$. Оба решения комплексные, но **не вещественные**.

## 6. Реализация математических операций на Python

В предыдущих уроках мы уже пользовались `int`, `Fraction` и `float`. Теперь добавим тип `complex`. **Каждый блок кода ниже самодостаточен**: необходимые переменные определены внутри блока, поэтому его можно запустить отдельно.

### 6.1. Вещественные числа: тип `float`

```python
# Число с десятичной частью
x = 2.5

print(x)           # 2.5
print(type(x))     # <class 'float'>
```

**Разбор:** `x = 2.5` связывает имя `x` с числом с плавающей точкой. Точка в Python используется как **десятичный разделитель**, в отличие от русской математической записи $2{,}5$.

Важно: `float` — компьютерный тип с конечной точностью, а **не** точный эквивалент бесконечного множества $\mathbb R$.

### 6.2. Комплексное число: буква `j` вместо $i$

В математике пишут $i$, но в Python мнимая единица записывается как `1j`:

```python
z = 3 + 4j

print(z)           # (3+4j)
print(type(z))     # <class 'complex'>
```

Запись `4j` означает $4i$ в математике. Обратите внимание: **`j` здесь не имя переменной**, а часть числового литерала. Python использует букву `j` по соглашению, распространённому в инженерных дисциплинах.

### 6.3. Создаём комплексное число через `complex()`

Пусть вещественная часть хранится в `a`, а мнимая — в `b`:

```python
a = 3
b = 4

z = complex(a, b)
print(z)           # (3+4j)
```

**Пошагово:**

1. `a = 3` — сохраняем вещественную часть.
2. `b = 4` — сохраняем мнимую часть.
3. `complex(a, b)` — создаём комплексное число $a+bi$.
4. `print(z)` — выводим `(3+4j)`.

Оба способа — `3 + 4j` и `complex(3, 4)` — создают один и тот же вид числового объекта.

### 6.4. Получаем вещественную и мнимую части

```python
z = -2 + 5j

print(z.real)      # -2.0
print(z.imag)      # 5.0
```

Атрибут `z.real` возвращает вещественную часть числа. Атрибут `z.imag` возвращает **коэффициент при мнимой единице**. Результаты имеют тип `float`.

Сравните с математикой:

$$
\operatorname{Re}(-2+5i)=-2,\qquad\operatorname{Im}(-2+5i)=5.
$$

### 6.5. Складываем и умножаем комплексные числа

```python
z1 = 2 + 3j
z2 = 1 - 2j

summation = z1 + z2
product = z1 * z2

print(summation)   # (3+1j)
print(product)     # (8-1j)
```

**Проверим вручную:**

$$
(2+3i)+(1-2i)=3+i,
$$

$$
(2+3i)(1-2i)=8-i.
$$

Как и в математике, Python учитывает $i^2=-1$ при умножении.

### 6.6. Сопряжённое число: `.conjugate()`

```python
z = 3 + 4j

conjugate_z = z.conjugate()
print(conjugate_z)  # (3-4j)
```

**Почему скобки после имени?** `conjugate()` — метод объекта: функция, которую мы вызываем у конкретного комплексного числа. Метод возвращает новое значение с противоположным знаком мнимой части.

### 6.7. Модуль комплексного числа: `abs()`

```python
z = 3 + 4j

distance = abs(z)
print(distance)    # 5.0
```

В математике:

$$
|z|=\sqrt{3^2+4^2}=5.
$$

В Python встроенная функция `abs()` подходит и для обычных вещественных, и для комплексных чисел. Для комплексного числа она возвращает **длину вектора от начала координат**.

### 6.8. Находим квадратный корень отрицательного числа

Модуль `math` рассчитан на вещественные результаты. Например, `math.sqrt(9)` равно `3.0`, но `math.sqrt(-1)` приводит к ошибке `ValueError`. Для комплексных результатов нужен модуль `cmath` (буква `c` — от *complex*):

```python
import math
import cmath

print(math.sqrt(9))      # 3.0
print(cmath.sqrt(-1))    # 1j
print(cmath.sqrt(-4))    # 2j
```

Здесь `1j` соответствует математической мнимой единице $i$, а `2j` соответствует $2i$. По соглашению `cmath.sqrt()` возвращает **главное значение квадратного корня**; например, у уравнения $x^2=-4$ есть два решения $\pm2i$, но функция возвращает одно — `2j`.

### 6.9. Почему нельзя написать `z1 > z2`?

```python
z1 = 3 + 4j
z2 = 1 + 2j

print(abs(z1) > abs(z2))  # True: сравниваем модули

try:
    print(z1 > z2)
except TypeError:
    print("Комплексные числа нельзя сравнить по порядку")
```

Здесь `try` означает «попробовать выполнить», а `except TypeError` — «обработать ошибку несовместимого сравнения». Поскольку **обычного порядка на комплексных числах нет**, выражение `z1 > z2` недопустимо. Но сравнение их вещественных модулей корректно.

### 6.10. Проверяем включение $\mathbb R\subsetneq\mathbb C$

```python
real_number = 7.0
complex_number = 7 + 0j

print(real_number == complex_number)  # True
print(type(real_number))              # <class 'float'>
print(type(complex_number))           # <class 'complex'>
```

**Математически** оба значения равны числу $7$. Однако в Python представлены **разными типами объектов**: `float` и `complex`. Это важное различие между математической принадлежностью множеству и программным типом данных.

## 7. Особенности вычислений в компьютере

### 7.1. Вещественные числа бесконечны, память ограничена

Множество $\mathbb R$ бесконечно и непрерывно. Компьютер не может хранить все вещественные числа в точном виде. Обычный `float` в Python чаще всего основан на двоичном формате IEEE 754 с ограниченной точностью.

Поэтому результат вычисления может немного отличаться от математически точного:

```python
x = 0.1 + 0.2

print(x)             # 0.30000000000000004
print(x == 0.3)      # False
```

В точной математике $0{,}1+0{,}2=0{,}3$. Разница появляется **не в математике**, а в двоичном представлении чисел внутри программы.

### 7.2. Как Python хранит `complex`

Комплексное число хранит две компоненты с плавающей точкой — вещественную и мнимую:

```python
z = 3 + 4j

print(type(z.real))  # <class 'float'>
print(type(z.imag))  # <class 'float'>
```

Следовательно, `complex` **не гарантирует бесконечной математической точности**. Например, в программе нельзя точно сохранить произвольное значение $\sqrt2+i\pi$ обычным объектом `complex`: его части будут приближёнными.

### 7.3. Приближённое сравнение

Для сравнения результатов вещественных вычислений часто применяют `math.isclose()`:

```python
import math

x = 0.1 + 0.2
y = 0.3

print(math.isclose(x, y))  # True
```

Для комплексных чисел аналогичная функция есть в `cmath`:

```python
import cmath

z1 = complex(0.1 + 0.2, 2.0)
z2 = complex(0.3, 2.0)

print(cmath.isclose(z1, z2))  # True
```

**Важно:** приближённое равенство зависит от выбранных допусков. `isclose()` **не доказывает** точное математическое равенство двух чисел.

### 7.4. Нельзя судить о множестве только по типу Python

- `int` хранит целые числа, включая натуральные.
- `float` хранит конечное множество представимых приближений вещественных чисел.
- `complex` хранит пары компонентов с плавающей точкой.
- Комплексный объект `7+0j` математически соответствует вещественному числу, хотя его тип — `complex`.

Проверка `type(x) == float` **не доказывает**, что математическое число иррационально. Например, и `0.5`, и приближение $\sqrt2$ могут иметь тип `float`.

## 8. Практическое применение в программировании

### Пример А. Координаты и расстояние

В компьютерной графике расстояние от начала координат до точки $(x,y)$ вычисляется по теореме Пифагора:

```python
import math

x = 3.0
y = 4.0

distance = math.hypot(x, y)
print(distance)   # 5.0
```

Та же геометрия лежит в основе модуля комплексного числа $3+4i$. Это связь между **геометрией** и **арифметикой комплексных чисел**.

### Пример Б. Сигналы и колебания

Комплексные числа позволяют компактно описывать амплитуду и фазу колебания. Пока достаточно понять два связанных понятия: **модуль** показывает величину, а **фаза** — направление на комплексной плоскости.

```python
import cmath

signal = 3 + 4j

amplitude = abs(signal)
phase = cmath.phase(signal)  # угол в радианах

print(amplitude)           # 5.0
print(round(phase, 3))     # 0.927
```

Подробное изучение тригонометрии, фаз и преобразований Фурье будет в следующих разделах учебника.

### Пример В. Решение квадратного уравнения

У уравнения $x^2+4=0$ нет вещественных корней. В комплексных числах они существуют:

```python
import cmath

root = cmath.sqrt(-4)

print(root)      # 2j
print(-root)     # (-0-2j) или -2j (детали отображения знакового нуля могут различаться)
```

**Смысл:** оба числа $2i$ и $-2i$ в квадрате дают $-4$, значит оба удовлетворяют исходному уравнению.

### Пример Г. Поворот точки на плоскости

Умножение комплексного числа на $i$ поворачивает соответствующий вектор на $90^\circ$ против часовой стрелки:

$$
i(a+bi)=-b+ai.
$$

Для точки $(2,1)$ получаем новую точку $(-1,2)$:

```python
z = 2 + 1j
rotated = z * 1j

print(rotated)   # (-1+2j)
```

Так проявляется геометрический смысл комплексного умножения. Другие повороты разберём после введения тригонометрии.

## 9. Типичные ошибки и ограничения

**Ошибка 1. «Иррациональные и комплексные числа — одно и то же».** Нет. Иррациональные числа входят в $\mathbb R$ и имеют нулевую мнимую часть при комплексной записи; например, $\sqrt2=\sqrt2+0i$.

**Ошибка 2. «Все комплексные числа невещественные».** Нет. Число $5=5+0i$ одновременно вещественное и комплексное.

**Ошибка 3. «Мнимая часть числа $3+4i$ равна $4i$».** Нет. $\operatorname{Im}(3+4i)=4$; выражение $4i$ — мнимая составляющая.

**Ошибка 4. «$i=-1$».** Нет. Выполняется **$i^2=-1$**, но сама мнимая единица $i$ не равна $-1$.

**Ошибка 5. «$\sqrt{-4}=-2$».** Нет: $(-2)^2=4$. У уравнения $x^2=-4$ решения $\pm2i$.

**Ошибка 6. «Комплексные числа можно сравнить знаками $<$ и $>$».** Обычный порядок на всём $\mathbb C$, совместимый с арифметикой, не существует. Можно сравнивать модули — это другая задача.

**Ошибка 7. «В Python нужно писать `i`».** Комплексный литерал Python содержит `j`: `3 + 4j`. Отдельная буква `i` была бы обычным именем переменной, если она не определена.

**Ошибка 8. «`abs(3+4j)` равно `3` или `4`».** Модуль находится по обеим координатам: $\sqrt{3^2+4^2}=5$.

**Ошибка 9. «`float` точно хранит всякое вещественное число».** Нет: обычный `float` представляет конечное число двоичных значений с ограниченной точностью.

**Ошибка 10. «`cmath.sqrt(-4)` сразу даёт два корня».** Функция возвращает **одно главное значение**; при решении уравнения $x^2=-4$ необходимо рассмотреть оба знака.

## 11. Краткие выводы и справочник формул

### 11.1. Математический справочник

| Символ или формула | Значение |
|---|---|
| $\mathbb R$ | Множество вещественных чисел |
| $\mathbb C$ | Множество комплексных чисел |
| $\mathbb R\subsetneq\mathbb C$ | Всякое вещественное число комплексно, но не наоборот |
| $i^2=-1$ | Определяющее свойство мнимой единицы |
| $z=a+bi$ | Алгебраическая форма комплексного числа |
| $\operatorname{Re}(z)=a$ | Вещественная часть |
| $\operatorname{Im}(z)=b$ | Мнимая часть |
| $\overline z=a-bi$ | Сопряжённое комплексное число |
| $|z|=\sqrt{a^2+b^2}$ | Модуль комплексного числа |
| $z\overline z=|z|^2$ | Связь сопряжения и модуля |
| $(a+bi)+(c+di)=(a+c)+(b+d)i$ | Сложение |
| $(a+bi)(c+di)=(ac-bd)+(ad+bc)i$ | Умножение |

**Итоговая цепочка:**

$$
\boxed{\mathbb N\subsetneq\mathbb Z\subsetneq\mathbb Q\subsetneq\mathbb R\subsetneq\mathbb C.}
$$

### 11.2. Справочник Python

| Python | Математический смысл |
|---|---|
| `2.5` | Число с плавающей точкой, тип `float` |
| `3 + 4j` | Комплексное число $3+4i$ |
| `complex(3, 4)` | Создание комплексного числа из двух частей |
| `z.real` | Вещественная часть |
| `z.imag` | Мнимая часть |
| `z.conjugate()` | Сопряжённое число |
| `abs(z)` | Модуль комплексного числа |
| `cmath.sqrt(-1)` | Главное значение квадратного корня: `1j` |
| `cmath.phase(z)` | Угол комплексного числа (в радианах) |
| `cmath.isclose(z1, z2)` | Приближённое сравнение комплексных чисел |

!!! summary "Самая важная мысль"
    **Математика** описывает целые множества чисел и их точные свойства. **Python** даёт конечные компьютерные представления и инструменты вычисления. Тип `complex` реализует арифметику комплексных приближений, но не превращает компьютер в хранилище всех чисел $\mathbb C$.

- **Основная теорема алгебры:** почему комплексных чисел хватает для корней многочленов.
- **Полнота вещественных чисел:** строгая теория $\mathbb R$ в математическом анализе.

(function () {
  function initialise() {
    document.querySelectorAll('[data-complex-lab]').forEach(function (lab) {
      if (lab.dataset.ready === 'true') return;
      lab.dataset.ready = 'true';
      const aInput = lab.querySelector('[data-a]');

      const code = lab.querySelector('[data-code]');
      const copy = lab.querySelector('[data-copy-code]');
      const reset = lab.querySelector('[data-reset]');
      const ns = 'http://www.w3.org/2000/svg';

      function node(tag, attrs, content) {
        const el = document.createElementNS(ns, tag);
        Object.keys(attrs || {}).forEach(function (key) { el.setAttribute(key, attrs[key]); });
        if (content !== undefined) el.textContent = String(content);
        plane.appendChild(el);
        return el;
      }

      function imaginaryPart(n) {
        return Math.abs(n) === 1 ? 'i' : Math.abs(n) + 'i';
      }
      function formatComplex(a, b) {
        if (b === 0) return String(a);
        if (a === 0) return (b < 0 ? '−' : '') + imaginaryPart(b);
        return String(a) + (b < 0 ? ' − ' : ' + ') + imaginaryPart(b);
      }
      function draw(a, b) {
        const cx = 300, cy = 200, step = 22, minimum = -8, maximum = 8;
        const x = function (n) { return cx + n * step; };
        const y = function (n) { return cy - n * step; };
        plane.replaceChildren();
        node('title', {}, 'Комплексное число ' + formatComplex(a, b) + ' на плоскости');
        for (let n = minimum; n <= maximum; n += 1) {
          node('line', {x1:x(n), y1:y(minimum), x2:x(n), y2:y(maximum),stroke:'currentColor','stroke-opacity':n===0?'.45':'.09','stroke-width':n===0?'1.5':'1'});
          node('line', {x1:x(minimum), y1:y(n), x2:x(maximum), y2:y(n),stroke:'currentColor','stroke-opacity':n===0?'.45':'.09','stroke-width':n===0?'1.5':'1'});
        }
        node('line', {x1:104, y1:cy, x2:501, y2:cy,stroke:'currentColor','stroke-width':'2'});
        node('line', {x1:cx, y1:380, x2:cx, y2:16,stroke:'currentColor','stroke-width':'2'});
        node('polygon',{points:'501,200 490,195 490,205',fill:'currentColor'});
        node('polygon',{points:'300,16 295,27 305,27',fill:'currentColor'});

          node('text',{x:x(n),y:cy+17,'text-anchor':'middle',fill:'currentColor','fill-opacity':'.85','font-size':'12'},n);
          node('text',{x:cx-12,y:y(n)+4,'text-anchor':'end',fill:'currentColor','fill-opacity':'.85','font-size':'12'},n);
        });
        node('text',{x:cx-8,y:cy+18,'text-anchor':'end',fill:'currentColor','font-size':'12'},'0');
